# Dataset

This project uses the Walmart M5 retail dataset for the financial/retail classification experiments.

The dataset is not included in this repository because it is a large third-party dataset.

## Obtaining the Dataset

Download the Walmart M5 dataset from its original authorized source and place the required files in this directory.

The project notebook documents the data loading, integration, cleaning and feature-engineering workflow.

## Expected Data

The project works with retail information including:

- Product identifiers
- Store information
- Sales information
- Pricing information
- Calendar/event information

Refer to the project notebook for the exact data preparation and feature-engineering workflow.

## Important

Do not commit the original dataset to GitHub.

The `.gitignore` file should also be configured to prevent accidental uploads of large dataset files.
