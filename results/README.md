# Results

This directory contains the documented model-comparison results from the MSc project.

## Model Comparison

| Model | Accuracy | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|
| Logistic Regression | 38.2% | 34.5% | 38.2% | 27.1% |
| Decision Tree | 74.7% | 74.7% | 74.7% | 74.7% |
| Random Forest | 57.6% | 57.6% | 57.6% | 57.6% |
| Gaussian Naive Bayes | 37.0% | 27.8% | 37.0% | 26.9% |

The Decision Tree produced the strongest documented performance in the experiment.

The results are provided for reference and should be interpreted in the context of the project's dataset preparation and experimental methodology.
